# ˚₊‧꒰ა ☁️ ໒꒱ ‧₊˚ Computação em Nuvem

> **Trabalho escolar — Desenvolvimento de Sistemas**

୨୧ Este projeto foi desenvolvido como parte de uma atividade escolar sobre **Computação em Nuvem**, com o objetivo de apresentar conceitos, características e aplicações dessa tecnologia de forma simples e visual.

୨୧ O site foi desenvolvido utilizando **HTML, CSS e Bootstrap**, buscando aplicar na prática conceitos de desenvolvimento web, organização de páginas, responsividade e interface de usuário.

### ✦ Objetivo

O trabalho tem como proposta transformar o conteúdo estudado em uma experiência web organizada, apresentando os principais conceitos relacionados à computação em nuvem e sua utilização no cotidiano e no mercado de tecnologia.

### ୨୧ Uso de Inteligência Artificial

A **Inteligência Artificial (IA)** foi utilizada como ferramenta de apoio durante o desenvolvimento do projeto, principalmente para:

* esclarecer dúvidas sobre programação e desenvolvimento web;
* auxiliar na identificação e correção de erros (*debugging*);
* criar e auxiliar na elaboração dos ícones e elementos visuais utilizados no site.

A IA foi utilizada como recurso de apoio ao desenvolvimento, enquanto a implementação e organização final do projeto foram realizadas pelos alunos.
